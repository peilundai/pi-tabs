# Support

This extension is unofficial and is not supported by Pi, Earendil, or Mario
Zechner.

## Extension issues

For editor-tab behavior, working-directory selection, path insertion, launch
settings, or the title-bar button:

- search [existing issues](https://github.com/peilundai/pi-tabs/issues);
- include the extension version, editor version, operating system, remote/local
  environment, and relevant **Pi Coding Agent** output-channel logs;
- remove secrets, tokens, model prompts, and private paths before posting.

Security-sensitive reports should follow [SECURITY.md](SECURITY.md), not a
public issue.

## Pi issues

For Pi models, sessions, authentication, providers, or CLI behavior, use the
official [Pi documentation](https://pi.dev/docs/latest) and
[Pi source repository](https://github.com/earendil-works/pi).
